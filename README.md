# 태풍 경로 탐구

2020~2025년 기상청 태풍 발표자료를 조회하고 날짜별 이동 경로를 지도에서 재생하는 학습용 시제품입니다.

## 실행

Node.js 18 이상을 설치한 뒤 프로젝트 폴더에서 다음을 실행합니다.

```sh
node start.mjs
```

브라우저에서 http://localhost:8787 을 열고 기상청 API허브 인증키를 입력합니다. 태풍목록 및 태풍정보+예측 API의 활용신청이 필요할 수 있습니다. 인증키는 저장하지 마세요.

기상청 API의 응답과 실제 동작은 개발 환경의 네트워크 제한으로 검증되지 않았습니다. 제공 범위에 따라 일부 연도 또는 태풍의 자료가 없을 수 있습니다. 대한민국을 통과한 태풍만 자동으로 필터링하지 않습니다.

이 버전은 서버가 필요하므로 GitHub Pages에서 그대로 실행되지 않습니다. 교육용이며 재난 대응용이 아닙니다.
