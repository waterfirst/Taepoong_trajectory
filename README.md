# 태풍 경로 탐구

기상청 태풍 발표자료로 2020~2025년 태풍의 이동 경로를 지도와 날짜 애니메이션으로 살펴보는 고등학교 과학 수업용 웹앱입니다. 날씨마루, API허브 활용신청, AI 활용 및 자료 검증 안내가 포함됩니다.

## GitHub Pages

`public/`의 정적 사이트를 GitHub Actions로 배포합니다. 태풍 데이터는 기상청 API에서 미리 수집한 자료이며, 방문자의 인증키는 필요하지 않습니다. 데이터는 자동 갱신되지 않습니다.

`main` 브랜치에 변경 사항을 푸시하면 Pages 배포 워크플로가 실행됩니다. GitHub 저장소 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택해야 할 수 있습니다.

## 로컬 실행

Node.js 18 이상에서 `node start.mjs`를 실행하면 기상청 API를 직접 조회하는 개발용 서버를 http://localhost:8787 에서 사용할 수 있습니다. 각각의 API 활용신청과 개인 인증키가 필요합니다. 인증키는 공개 저장소에 올리지 마세요.

`build-static.mjs`는 개발용 화면과 안내로 `public/index.html`을 생성합니다. 생성 전 `public/data/`에 같은 형식의 연도별 자료가 필요합니다.

## 출처 및 한계

자료: 기상청 API허브 태풍목록 및 태풍정보+예측. 실제 발생한 모든 태풍이 아니라 API가 반환한 발표 자료입니다. 대한민국에 영향을 주거나 중심이 육상을 통과한 태풍을 자동 선별하지 않습니다. 실시간 예보나 재난 대응에 사용하지 마세요.
