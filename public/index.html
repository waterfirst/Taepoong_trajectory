교사용 · 학생용

직접 만들어 보는 태풍 경로 웹앱

기상 데이터를 읽고, AI와 협력하여 지도에 나타내는 수업 활동입니다. 이 사이트는 2020~2025년 기상청 발표 자료를 미리 수집한 교육용 예시입니다.

1. 날씨마루에서 주제 살펴보기

  1. 기상청 날씨마루에 접속해 기상융합서비스와 분석환경을 살펴봅니다. 데이터와 분석환경 이용 절차는 날씨마루의 안내를 확인합니다.
  2. 탐구 질문을 정합니다. 예: “태풍 힌남노는 언제 한반도에 가까워졌고, 이후 어느 방향으로 이동했을까?”

2. 기상청 API허브에서 자료 신청하기

날씨마루와 기상청 API허브는 서로 다른 서비스입니다. 아래 API 신청과 인증키 발급은 API허브에서 진행합니다.

  1. API허브에 회원가입하고 로그인한 뒤 안내에 따라 인증키를 발급받습니다. 학교 계정이나 학생 가입은 학교 방침을 따릅니다.
  2. 태풍 API 목록에서 태풍정보 → 1.1 태풍목록과 1.2 태풍정보+예측의 API 활용신청을 각각 합니다. URL을 복사하는 것과 활용신청은 다릅니다.
  3. 목록에서 연도(YY), 경로에서 태풍번호(typ)를 지정합니다. mode=0은 발표된 분석 자료, LAT/LON은 위도·경도, FT_TM은 시각(UTC)입니다. 받은 응답의 도움말로 열과 단위를 확인합니다.

3. AI와 함께 웹앱 만들기

아래 요청을 AI에 전달하고, API 명세에서 필요한 항목을 추가로 알려 주세요. 인증키는 AI 대화, GitHub 저장소, 공개 코드에 넣지 않습니다.

고등학교 과학 수업에서 기상청 API허브의 태풍 목록과 태풍정보+예측 자료를 이용해 웹앱을 만들고 싶어. 연도와 태풍을 선택하면 기상청 분석 경로의 위도·경도를 지도에 표시하고, UTC 시각을 한국시간으로 바꾸어 재생하는 HTML, CSS, JavaScript 코드를 만들어 줘. API 인증키는 코드에 넣지 말고, 사용 방법과 자료가 없을 때의 안내도 포함해 줘. 코드의 각 부분을 고등학생이 이해하기 쉽게 설명해 줘.
  1. AI가 만든 코드를 읽고 데이터의 수집, 지도 표시, 날짜 변환 부분을 찾아 설명해 봅니다.
  2. API 응답 한 줄과 지도에 표시된 위치·날짜를 비교합니다. 예를 들어 힌남노의 2022-09-05 21:00 UTC는 9월 6일 06:00 KST입니다.
  3. AI에게 오류를 질문할 때 인증키와 개인정보를 지운 오류 메시지만 전달합니다.

4. 수업에서 해석하기

태풍 두 개를 골라 이동 방향, 한반도와의 거리, 날짜를 비교해 봅니다. 지도에 표시된 점은 발표된 시각별 중심 위치이므로 점 사이에서 정확히 어느 지점을 통과했는지는 단정할 수 없습니다. 태풍의 영향 범위도 중심 경로와 다릅니다. 출처, 자료의 기간, AI 활용 과정과 한계를 함께 기록하세요.

자료 출처: 기상청 API허브, 태풍정보(기상청 발표). 경로는 실시간 예보가 아니며, 대한민국 통과 태풍만 자동으로 선별하지 않습니다. 재난 대응에는 기상청 공식 예보를 이용하세요.
